# Synthetic Cohort

Synthetic data for the Heartwood reference platform.
The values were generated by a pseudo-random program and describe no real person.

| File | Content |
|---|---|
| `participants.csv` | One row for each of 24 participants: identifier, age group, site and enrollment date |
| `measurements.csv` | Two visits for each participant: systolic and diastolic blood pressure in mmHg and heart rate in beats per minute |
