Conformance checks use the versioned specification and this schema together.
The schema's CreateTaskResult is flat, as in the versioned example; the specification's
reference to an embedded task object is inconsistent with that shape.
The versioned missing-capability error code is -32021.
Heartwood's checks for sensible durations and timestamp ordering are profile checks;
the upstream schema alone does not enforce them.
The versioned completed-task examples omit resultType inside the original tool result.
The checker accepts that nested shape while requiring resultType on outer results;
this is a limited compatibility interpretation, not complete core-protocol validation.
